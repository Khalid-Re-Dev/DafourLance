# Arabic guide audio provenance

These eight MP3s are AI-generated narration of DafourLance's guide copy. They use the fixed `af_msa` voice; no user-supplied or named person's voice was cloned.

- Model and voicepack: Nabra-82M-v0.1 by oddadmix, declared Apache-2.0 in its model card.
- Pinned model revision: `adf6abf35c46db5f2b08803b5067a12c759b1ee1`.
- Source: https://huggingface.co/oddadmix/Nabra-82M-v0.1/tree/adf6abf35c46db5f2b08803b5067a12c759b1ee1
- Engine: Oddadmix's Kokoro fork, commit `df50e07df746aec0bd7a6f237752d7109ace0b3d`, Apache-2.0.
- Source: https://github.com/Oddadmix/kokoro/tree/df50e07df746aec0bd7a6f237752d7109ace0b3d
- Upstream acknowledgments: hexgrad/Kokoro-82M (Apache-2.0), StyleTTS2 (MIT), kikiri-tts/semidark training recipe, and espeak-ng/Misaki phonemization.
- The model card is retained in MODEL_CARD.md and the Apache license in APACHE-2.0.txt.
- Exact texts, model input hashes, output hashes, synthesis settings and tool versions are in generation.json.

Only rendered audio is shipped to visitors. Model weights, Python packages, and speech-model inference are not part of the website bundle. The deprecated Kareem evaluation voice is not used in these files.
